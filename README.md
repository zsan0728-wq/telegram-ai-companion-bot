# Telegram 陪聊机器人

核心用途：你不在时，在 Telegram「聊天自动化」授权的私聊里代聊；直接私聊机器人，用来测试回复风格、贴纸和上下文。

## 日常使用

1. 在 Telegram 给机器人配置聊天自动化，仅选择需要代聊的联系人，并允许回复消息。
2. 离开前运行 `启动机器人.bat`，或用 `后台静默运行.vbs` 隐藏窗口运行。
3. 回来后运行 `停止机器人.bat`。本地程序停止后就不会代聊，没有额外的离开模式开关。
4. 私聊机器人直接测试，不需要 `[测试]` 前缀；旧前缀仍兼容。

程序运行期间会响应授权聊天里的新消息，**不会检测你是否在线或人在电脑前**。启动时丢弃停机期间的积压消息，避免突然补发旧对话。你在正式聊天中亲自插话，会取消该聊天正在生成和排队的旧回复；之后对方的新消息仍会触发代聊，回来时请停止程序。

## 测试与正式代聊

- 两种入口使用同一套人设、模型调用、贴纸选择和发送逻辑。
- 测试记忆与正式聊天独立；不同联系人也有独立记忆。继续使用原有 `chat_history.json`。
- 保留现有恋人陪聊风格；在 `config.py` 的 `SYSTEM_PROMPT` 调整。
- 只处理私聊，不处理群聊、编辑过的消息，也不会回复机器人自身发送后回流的消息。
- 支持文字、贴纸，以及带文字说明的媒体。不会识别图片或转写语音；正式聊天中无文字说明的图片和语音暂不回复。
- 适用于你自己的单个 Telegram 账号；不要让多个账号共用这份数据目录。

## 贴纸

直接给机器人发贴纸即可收藏；重复贴纸会更新文件引用，不重复收藏。正式代聊收到的贴纸不会加入收藏库。

单独发贴纸或纯 emoji 时，程序只回一张收藏的贴纸，不调用语言模型、不解读表情、不回复文字。贴纸功能关闭或收藏为空时，不发送贴纸。

每轮先等待约 2 秒，合并紧接着发送的消息：如果先发一句话、再发表情，模型只处理那句话，先回复文字、再配一张贴纸。连续多个表情合并为一次贴纸回应。超过合并窗口的消息进入下一轮，同一聊天按顺序回复。窗口长度由 `MESSAGE_MERGE_SECONDS` 控制。

纯文字轻松闲聊时鼓励 AI 主动搭配贴纸。发出贴纸后的下一轮暂停自动搭配，第 2 轮恢复资格，是否发送仍取决于语境；连发多张不延长冷却。回应用户发来的表情不受此冷却限制；同轮文字明确要求“只回文字”时优先遵守。

明确要求“再发一张”“再发2张”“连续发送3个贴纸”时跳过冷却，AI 漏写标记也会自动补足。每轮最多 3 张，同一轮不重复；库存不足只发已有数量。“别发贴纸”“只回文字”会禁止本轮贴纸。

## 私聊命令

- `/start`、`/help`：查看用法。
- `/reset`：只清空当前测试聊天的记忆，不影响正式代聊。
- `/stickers`：查看收藏。
- `/delsticker`：回复要删除的贴纸后发送此命令；也可先用 `/stickers` 查看编号，再发送 `/delsticker 17` 按编号删除。删除后编号重新排列。以后重新发送该贴纸会再次收藏。复制为等宽格式的命令也能识别。
- `/clearstickers`：清空共享贴纸库，测试和正式代聊都会受影响。

这些命令只在直接私聊机器人时生效，正式聊天里的同名文字不会执行管理操作。机器人私聊用作你的测试入口，请不要将入口作为公共服务分享。

## 安装与配置

需要 Python 3.10 或更新版本。在项目目录执行：

```powershell
python -m pip install -r requirements.txt
```

在 `config.py` 填写 Telegram Bot Token 和模型 API Key；保留现有配置即可继续使用。通过 BotFather 启用机器人的 Business Mode，再在 Telegram 配置聊天自动化连接。

常用配置：`MODEL`、`SYSTEM_PROMPT`、`MAX_HISTORY`、`ENABLE_STICKERS`、`STICKER_COOLDOWN`、`MESSAGE_MERGE_SECONDS`。API Key 和 Bot Token 不要分享。

## 稳定性与排查

- 模型请求使用异步调用，不同聊天可以同时处理，同一聊天按顺序回复。
- 连接停用、没有回复权限、身份无法确认时不代发消息。
- 只有真正发送成功的内容才作为 AI 回复写入记忆；发送失败不自动重发，以免网络超时造成重复消息。
- 最近的对话会保存到本机，调用模型时会把当前聊天的有限历史发送到配置的模型服务。
- 日志位于 `logs/bot.log`，自动轮转，记录启动、异常和贴纸发送结果；不会主动记录消息正文，配置中的密钥会被遮盖。
- 同一台机器只允许一个实例。停止脚本只停止本目录启动、占用机器人单实例端口的进程。

离线回归测试（不向 Telegram 或模型发送请求，不修改真实聊天记录）：

```powershell
python -m unittest -v
```

`bot.py` 负责消息与陪聊流程，`runtime_support.py` 负责本地保存和日志。
